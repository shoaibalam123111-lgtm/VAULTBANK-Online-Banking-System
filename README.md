# 🏦 VAULTBANK - Online Banking System

A Java-based Online Banking System developed as a college project using **Java, JDBC, MySQL, Jakarta Servlets, and Apache Tomcat**.

It demonstrates database connectivity, user authentication, customer information management, and web integration.

---

## 🚀 Features

### 👤 Customer

- Customer Login
- Customer Information
- Account Balance
- Database-based Customer Data
- Customer Servlet API

### 🔐 Authentication

- Login using Email and Password
- Role-based User Information
- MySQL Database Authentication

### 🛠️ Admin

- Admin User Structure
- User Management Structure
- Banking System Management Structure

---
